About Our Research

Exploring how multi-agent AI can simplify early-phase software development, improve design consistency, and support developers in creating software designs.

Faster Design Process

Reduce repetitive manual design tasks through AI-assisted requirement analysis, architecture planning, and design generation.

Improved Design Consistency

Identify inconsistencies between software design artifacts through automated validation and structured information sharing.

Connected Development Workflow

Connect requirements, architecture, detailed design, and UI/UX activities through a coordinated multi-agent framework.

Reduced Design Errors

Detect potential design issues, unnecessary elements, and naming inconsistencies before implementation begins.

Key Components

Four specialized AI agents operating within a coordinated framework to support early-phase software design activities.

01

Requirement Analysis Agent

Analyzes software requirements and organizes them into structured specifications that guide subsequent design activities.

02

High-Level Architecture Agent

Transforms software requirements into high-level architectural designs, defining major system components, their responsibilities, and interactions.

03

Low-Level Design Agent

Generates UML class, sequence, and ER diagrams using requirements and architectural inputs. Applies rule-based validation to identify inconsistencies, naming issues, and potential overdesign.

04

UI/UX Design Agent

Supports user interface design and evaluates generated designs against usability and accessibility guidelines to improve the overall user experience.
